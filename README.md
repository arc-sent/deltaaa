# Δ Delta — статистика VK-групп

Telegram-бот, который следит за подписчиками твоих VK-сообществ и выдаёт отчёты:
**коротко — текстом в сообщении + график**, **подробно — файлом PDF** по кнопке.

```
Раз в час: VK API (members_count)  →  SQLite (снимки во времени)
                                             │
                              ┌──────────────┴───────────────┐
                              ▼                               ▼
              Отчёт по группе (текст + график + PDF)   Сравнение групп
                              │                               │
                              └───────────► Ежедневный дайджест по утрам
```

VK **не отдаёт историю числа подписчиков** за прошлое, поэтому бот сам снимает
`members_count` по расписанию и копит точки — из них строятся графики роста/оттока.
Охваты и просмотры (`stats.get`) добавляются в отчёт, **если токен принадлежит
администратору** сообщества.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env      # впиши TELEGRAM_TOKEN (у @BotFather)
python bot.py
```

## Деплой в Docker

```bash
cp .env.example .env      # впиши TELEGRAM_TOKEN (и по желанию ADMIN_IDS, TOKEN_KEY)
docker compose up -d --build
docker compose logs -f    # смотреть логи
```

`docker compose` сам подхватывает переменные из `.env`. Данные (БД снимков, ключ
шифрования `token.key`, состояние бота) лежат в томе `./data` на хосте и
переживают пересборку/рестарт контейнера. Обновление после правок кода:

```bash
docker compose up -d --build
```

> ⚠️ Если задал `TOKEN_KEY`, не меняй его после того, как токены уже зашифрованы —
> иначе их не расшифровать (бот попросит ввести VK-токен заново).

## Как пользоваться (меню бота)

1. **🔑 Токен** — задать VK-токен (инструкция через Kate Mobile прямо в боте).
2. **👥 Группы** — добавить группы по ссылке `vk.com/club123` / короткому имени
   (ID и название бот определяет сам; сразу снимается первый замер подписчиков).
3. **📈 Отчёт** — выбрать группу → текстовая сводка + график. Кнопки:
   - период **7 / 30 / 90 дней**;
   - **📄 Подробный PDF** — многостраничный отчёт: сводка, динамика подписчиков,
     дневной прирост/отток, охваты и просмотры (если доступны).
4. **📊 Сравнение** — отметить несколько групп → общий график + таблица приростов,
   тоже с выгрузкой в PDF.
5. **📅 Дайджест** — включить утреннюю сводку (время задаётся в `.env`).

## Что в отчёте

- **Подписчиков сейчас**, изменение за период (абсолют и %), было в начале.
- **Средний темп** прироста в день.
- **Лучший день** (максимальный прирост) и **день оттока** (максимальная просадка).
- **Охваты / просмотры** — из `stats.get`, только для админов сообщества.

> ⚠️ «Отток» считается по чистому изменению `members_count` за день (VK не отдаёт
> отдельно число отписавшихся). Дни с отрицательной динамикой помечаются как отток.

## Переменные окружения

| Переменная | По умолчанию | Значение |
|---|---|---|
| `TELEGRAM_TOKEN` | — | токен бота (обязательно) |
| `ADMIN_IDS` | — | ID админов через запятую (видят все ошибки в `/errors`) |
| `COLLECT_INTERVAL_MINUTES` | 60 | как часто снимать число подписчиков |
| `DIGEST_HOUR` / `DIGEST_MINUTE` | 10 / 0 | когда слать дайджест (МСК); пусто = выкл |
| `ERROR_RETENTION_DAYS` | 5 | сколько хранить логи ошибок |
| `ERROR_CLEANUP_INTERVAL_DAYS` | 5 | как часто чистить логи |
| `TOKEN_KEY` | — | ключ шифрования токенов (иначе `data/token.key`) |

## Структура

| Файл | Роль |
|---|---|
| `bot.py` | Telegram-UI: токен, группы, отчёт, сравнение, дайджест, `/errors` |
| `collector.py` | снятие снимков `members_count` по всем группам |
| `scheduler.py` | планировщик: периодический сбор + ежедневный дайджест |
| `reports.py` | текстовые отчёты, PNG-графики, PDF (matplotlib) |
| `vk.py` | VK API: резолв групп, `members_count`, `stats.get` |
| `db.py` | SQLite: users / vk_groups / snapshots / settings / error_logs |
| `crypto.py` | прозрачное шифрование VK-токенов в БД |

## Команды

`/start` · `/report` · `/errors` · `/admin` · `/cancel`
